# Mask2Former

Source package for MDSTL's optional Mask2Former integration. The primary
upstream source is `https://github.com/zhang-tao-whu/DVIS_Plus.git`,
subdirectory `DVIS_Plus/mask2former/**`, based on
`https://github.com/facebookresearch/Mask2Former`.
